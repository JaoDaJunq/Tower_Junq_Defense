# Tower Junq Defense

Protótipo web de tower defense do universo Junq.

## Primeira versão jogável: Jardim da Lua

- Coloque João como torre em uma das plataformas de origami.
- Inicie ondas de raposas de papel.
- As torres atacam automaticamente com golpes de katana.
- Ganhe selos, posicione mais torres e proteja o jardim.

Abra `index.html` em um servidor estático. Para rodar localmente:

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.

O jogo e os assets ainda estão em protótipo. Os conceitos de Atol das Dobras, Bosque de Bambu de Papel e Porto dos Torii permanecem reservados para futuras fases.
